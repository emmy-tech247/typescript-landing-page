## Getting Started

### Prerequisites

Install the following:

- Node.js
- npm
- Git

Check your installation:

```bash
node --version
npm --version
git --version
```

### 1. Clone the repository

```bash
git clone https://github.com/emmy-tech247/typscript-landing-page.git
```

### 2. Navigate to the project directory

```bash
cd typscript-landing-page
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

If the project uses Vite, run:

```bash
npm run dev
```

If that command is not available, check the `scripts` section in `package.json` for the correct development command.

### 5. Build the project

```bash
npm run build
```

Resolve any TypeScript or build errors before deploying the project.
